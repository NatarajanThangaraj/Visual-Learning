Welcome to your new job at Rapido! Your task is to design the core Java classes that handle ride bookings. You will create normal Java classes to represent real-world things, make sure their data is secure (private), and make them interact with each other.

Before you submit

  • Six classes exist and compile: Passenger, Vehicle, Rider, Ride, RapidoApp, RapidoCompany.
  • Every variable in every class is private — nothing is reachable from outside except through a method you wrote.
  • Running RapidoApp prints a receipt and then the passenger's new balance.
  • With a wallet of Rs. 500, a Bike at Rs. 10 per km and a distance of 15 km, the balance printed at the end is 350.0.
  • Lower the wallet below the fare, run it again, and Insufficient funds! appears.
