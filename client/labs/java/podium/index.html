    Build Podium in the console.

    You have just played a room for three. Now rebuild it in Java: one server program and three copies of a client program, each in its own terminal window. When your programs run, they should behave exactly like the game you just played.

    The flow

    flowchart TD
  SM[ServerMain] --> QS["QuizServer<br/>opens a ServerSocket, waits for players"]
  QS -->|load questions| QB["QuestionBank<br/>reads questions.txt"]
  CM["ClientMain x3"] --> QC["QuizClient<br/>asks the name, connects"]
  QC -->|connects| QS
  QS -->|one thread per player| CH[ClientHandler]
  CH -->|"tell everyone: Raj connected"| QS
  QS -->|"3 players: start the quiz"| CH
  CH -->|"send a question, check the answer"| QC
  CH -->|"all 10 correct: record the finish"| QS
  QS -->|"tell everyone: Ram won 1st prize"| QC
  QS -->|quiz over| RS["ResultStore<br/>writes results.txt"]

    The classes

    classDiagram
  class ServerMain {
    +main(String[] args)
  }
  class QuizServer {
    -ServerSocket serverSocket
    -List~ClientHandler~ players
    -List~Question~ questions
    -List~String~ finishOrder
    -CountDownLatch roomFull
    +start()
    +addPlayer(ClientHandler p) boolean
    +waitForRoom()
    +broadcast(String msg, ClientHandler except)
    +recordFinish(ClientHandler p) int
    +removePlayer(ClientHandler p)
  }
  class Thread
  class ClientHandler {
    -Socket socket
    -BufferedReader in
    -PrintWriter out
    -String playerName
    -int current
    +run()
    +send(String msg)
  }
  class Question {
    -String text
    -int answer
    +isCorrect(int value) boolean
  }
  class QuestionBank {
    +load(String file) List~Question~
  }
  class ResultStore {
    +save(List~String~ finishOrder)
  }
  class ClientMain {
    +main(String[] args)
  }
  class QuizClient {
    -Socket socket
    -PrintWriter out
    -Scanner keyboard
    +connect()
    +play()
  }
  class ServerListener {
    -BufferedReader in
    +run()
  }
  ServerMain --> QuizServer
  QuizServer o-- ClientHandler : manages all players
  Thread <|-- ClientHandler
  QuizServer --> QuestionBank
  QuizServer --> ResultStore
  QuizServer o-- Question
  ClientMain --> QuizClient
  QuizClient --> ServerListener : starts
  Thread <|-- ServerListener
  QuizClient ..> QuizServer : connects over a socket
