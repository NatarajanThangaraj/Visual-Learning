The flow

flowchart TD
  M[Main] --> D["Dashboard<br/>(client socket created)"]
  D -->|"Ask username<br/>(set it to the thread)"| GC["Game Center<br/>(client connected to server)"]
  GC -->|store score| FH[File Handling]
  FH -->|get all questions and answers| GC
  GC -->|if Sprint| S["Sprint<br/>Run 60 sec<br/>Show question to the client and get answer"]
  GC -->|if Duel| DU["Duel<br/>Waiting for another client<br/>If new client connected, start the game"]
