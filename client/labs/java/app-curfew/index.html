      Behind App Curfew

      Searching the list and tapping "Send home" is the whole trick: ask the operating system what's running, find the one you mean, and tell the operating system to end it. No app can tell you that from the inside — you have to go through the OS.

      The task

      Write a Java program that lists every running process, finds the one you name, and shuts it down — the same two steps "Send home" hides behind a button.

      • Run Runtime.getRuntime().exec("tasklist") on Windows (or exec("ps -A") on Mac/Linux) and wrap process.getInputStream() in a BufferedReader.
      • Call readLine() in a loop until it returns null, checking each line for the app name you were given.
      • When a line matches, split it on whitespace to pull out the PID — the second column in both tasklist and ps -A output.
      • Run a second Runtime.exec() — "taskkill /PID " + pid + " /F" on Windows, or "kill -9 " + pid on Mac/Linux — to end it.
      • If no line matches the name, print that nothing by that name is running instead of guessing a PID.
      A process never announces when it ends — your program only knows because it asked the OS, the same way "Send home" only knows once it has searched the list.
