PROGRAMMING ASSIGNMENT — THE SONGBOX ENGINE
Your program should work for any songs.txt with these five fields — more songs, different artists, genres you have never heard of. Nothing about your code should assume this particular library. Read the genre and artist menus out of the file; never hard-code the lists you saw here.
