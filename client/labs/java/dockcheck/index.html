Behind DockCheck

Tapping "Check" never looks inside the dock itself — it asks the network what every dock on this block is currently doing, then reads the one line that mentions the dock you asked about.

What the terminal sees

Which port do you want to check? 8080 Running: netstat -ano | find "8080" TCP 0.0.0.0:8080 0.0.0.0:0 LISTENING 9044 Port 8080 is IN USE (PID 9044) Which port do you want to check? 8081 Running: netstat -ano | find "8081" (no matching line) Port 8081 is FREE

The task

Write a Java program that asks the operating system whether a port is being listened on — the same question "Check" is asking about a dock.

  • On Windows, run Runtime.getRuntime().exec("netstat -ano") and read its output through a BufferedReader wrapping getInputStream().
  • On Mac/Linux, run exec("lsof -i :" + port) instead.
  • Check each line for :<port> followed by LISTENING (Windows) — or any output at all (Unix) — and pull the PID from the last column when it matches.
  • If readLine() reaches the end of the stream with no match, the port is free.
Read the stream as you go, not after calling waitFor() — a command with a lot of output can fill the OS pipe buffer and hang your program if nothing is draining it.
