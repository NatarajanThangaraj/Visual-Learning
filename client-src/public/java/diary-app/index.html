Your Java program should hold up to every one of these.

  • The accounts file holds one line per user — the name, the password and the folder that belongs to them.
  • Every user has their own folder, named after them, holding one file per month.
  • A month file holds one record per written day, and never two records for the same day.
  • Signing up with a name someone already took is refused, not overwritten.
  • An empty page is not saved.
  • A month nobody has written in opens blank instead of failing.
  • Writing that happens to contain your separator mark still comes back whole.
  • Quit the program, run it again — every page is still there. That is the whole point.
