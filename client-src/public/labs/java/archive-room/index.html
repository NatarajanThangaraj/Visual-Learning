Somewhere in these eight drawers is every document that mentions your word. Open them all at once instead of one by one.

Try “refund” or “warranty”.

    Behind Archive Room

    "Search all drawers" never looks inside a document — it hands the word to a tool built for exactly this, and only reads back the names of the files that tool found.

    The task

    Write a Java program that searches every file under a directory for a keyword, using a tool the OS already has — the same shortcut "Search all drawers" is taking.

    • On Mac/Linux, run Runtime.getRuntime().exec(new String[]{"grep","-rl",keyword,path}).
    • On Windows, run exec("findstr /s /m \"" + keyword + "\" *.txt") from inside the archive directory instead.
    • Wrap process.getInputStream() in a BufferedReader and call readLine() in a loop until it returns null — each line is one matching file's path.
    • Collect every path into a List<String>; print a numbered list when the loop ends, or "No matches found." if the list is empty.
    -l and /m tell the tool to print file names only, never the matching line itself — exactly what the Play tab shows: a file name sliding out, never a text preview.
