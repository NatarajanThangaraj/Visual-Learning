Before you hand in

Don’t trust the screen because it looks right. Instead, ask: What did I EXPECT to happen? ↓ What ACTUALLY happened? ↓ Which OBJECT holds the wrong value? ↓ Which METHOD last changed it? ↓ What CONCEPT did that line misunderstand? Expected ≠ Actual → a question, not a guess.
