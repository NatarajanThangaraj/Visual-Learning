    Behind Detail Bay

    Every other "Send to Detail Bay" button is disabled the moment one car goes in, because the front desk is a single program and it is standing still, waiting for that one car to come all the way back.

    The task

    From the master program, start a second, completely independent Java program and wait for it to hand its results back — exactly what the front desk does with the bay.

    • Launch a separate program with Runtime.getRuntime().exec("java HelloWorld") — it runs in its own JVM, with its own main(), unrelated to your call stack.
    • Call process.waitFor() right after: this blocks that line, so your program does not continue until the child finishes — unlike starting a Thread, which would run alongside it.
    • Once waitFor() returns, wrap process.getInputStream() in a new BufferedReader(new InputStreamReader(...)) and read every line the child printed with readLine().
    • Print each line inside your own program's console, as if it were your own output.
    This is exactly why sending a car to the bay freezes every other "Send" button: the front desk is blocked inside waitFor() until that one car's receipt comes back.
