🎓 Teacher Moment
Everything you just designed has a name in Java.
Monster properties = Variables
Monster itself = Object / Class
Health decreasing = Assignment
HP = 0 → what happens = if-statement
Fight 3 monsters in order = Loop
Different monster types = Inheritance / Polymorphism
Shop inventory = ArrayList
Repeat attacks on Boss = While loop
100 monsters = Array / Collection
Statistics = Variables + Methods
