The Collection framework hierarchy
Every collection in Java is a point on this map. Interfaces describe the behaviour you need — ordered? unique? sorted? first-in-first-out? Classes are the concrete implementations that deliver it. Choose the interface for your variable type, and the class for the performance you need.
Click any box to open its topic page.

Declare the interface

Legacy nodes
Vector, Stack and Hashtable are Java 1.0 survivors. Prefer ArrayList, ArrayDeque and HashMap.
