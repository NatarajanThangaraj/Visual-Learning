class AppConfig { static String userPlan = "FREE"; static String appTheme = "LIGHT"; static int maxUploadMB = 100; }

Templates.java
class Templates { void useTemplate() { if (AppConfig.userPlan.equals("PRO")) { System.out.println("Template added"); } else { System.out.println("Upgrade required"); } } }
Videos.java
class Videos { void useVideo() { if (AppConfig.userPlan.equals("PRO")) { System.out.println("Video added"); } else { System.out.println("Upgrade required"); } } }
Notice: Both Templates and Videos access AppConfig.userPlan — the same static field. No object of AppConfig is created. The value belongs to the class itself.
